# 2026-08-15 网站体验与动效优化

## 目标

在不改变“不息”现有暖纸色、中文编辑感和信息架构的前提下，改善首页排版、移动导航、交互反馈、动效一致性与可访问性。

## 变更

- 重排首页主标题为两段语义完整的行组，并单独校准窄屏字号，避免中文短句出现孤字断行。
- 移除首页三个内容区上方的英文眉题，让中文标题直接承担层级，降低模板感。
- 为首页加入按需加载的 GSAP 动效：轨道图形的单次编排、桌面精细指针响应，以及仅对首屏以下内容生效的轻量滚动位移。
- 使用 `gsap.matchMedia()` 尊重 `prefers-reduced-motion`，使用 `quickTo()`、transform 与一次性 ScrollTrigger 控制运行成本；GSAP 仅在首页加载。
- 将移动导航改为来源明确的下拉过渡，采用打开 250ms、关闭 150ms 的非对称时序；补齐 `aria-expanded`、`aria-hidden`、`inert`、Esc 关闭、外部点击关闭和焦点返回。
- 新增语义动效 token，统一按钮、导航和内容行的时长与缓动；所有动效保留减弱动效兜底。
- 为内容行增加 4px 的低频 hover 位移反馈；没有使用 `transition: all` 或布局属性动画。
- 去除项目预览中的装饰性重复网格，以更接近真实界面骨架的内容条和组件占位替代。
- 新增主题色元信息与 SVG favicon，消除浏览器对 `/favicon.ico` 的无效请求。

## 验证

- `npm run build`：Astro 检查 0 errors、0 warnings、0 hints；9 个静态页面构建成功。
- Playwright 生产预览：检查首页、项目、文章、相册、关于和定制 404。
- 在 1440×900 与 390×844 视口检查首页；移动菜单验证打开、关闭与 Esc 焦点返回。
- Impeccable 检测发现并修复 1 项装饰性网格建议。

## 说明

- 项目仍保持 Astro 静态生成，没有引入 React、客户端状态框架、CMS 或数据库。
- `gsap-react` 仅用于确认 React 专用 hook 不适用于当前 Astro 项目，因此没有引入 `@gsap/react`。
- `npm audit --omit=dev` 仍报告 Astro 6 依赖链中的 1 个低危与 2 个高危项；自动修复要求升级到 Astro 7，属于框架主版本迁移，本次没有越界执行。
