# CMS 图片上传

照片、项目封面和档案叠放图片保留原有文件选择与移除功能，并支持：

- 虚线区域位于照片标题和说明下方，宽屏、窄屏均使用相同顺序。
- 将一张图片拖入该区域，或点击框内的“选择文件”按钮打开文件选择器。
- 聚焦该区域后按 `Command+V` 或 `Ctrl+V` 粘贴复制的图片；无需额外的粘贴按钮，也不通过点击读取剪贴板。
- 添加图片后隐藏选择区域，移除图片后重新显示。点击已添加的缩略图，或聚焦缩略图后按 Enter / 空格，可放大查看；点击关闭按钮或按 Esc 退出预览。
- 已添加图片时，“标题＋描述”作为左侧文字组，右侧显示垂直居中的“移除”按钮；标题与描述保留原有间距，按钮使用半透明红色背景和红色文字。

图片会先显示在当前表单中，点击“创建”或“保存”后才写入内容。移除照片时不立即显示必填错误，点击“创建”或“保存”时才校验。照片仍由原有流程自动压缩、更新尺寸并清理敏感元数据。一次接收一张图片，超过 80 MB、文件损坏或格式不符时显示提示，保留已有图片。

照片宽度和高度由处理后的发布资产自动读取，不在 CMS 表单中提供手动输入。内容记录仍保存这些数值，供图片比例计算和构建校验使用。卡片比例用于摄影页缩略图高度与分栏，照片方向用于横竖样式和首页竖图筛选；保存后两者也会根据实际宽高自动更新。

项目和文章的正文编辑器支持将图片拖入正文，或在正文中用相同快捷键粘贴；入口旁显示操作提示。文字粘贴保持编辑器原有行为。保存前为有信息意义的正文图片填写准确的替代文本。
