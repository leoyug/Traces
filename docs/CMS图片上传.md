# CMS 图片上传

编辑页字段说明以清楚为先，再精简文字：说明用途、格式和影响操作的规则，避免只写默认值却让人不知道字段用在哪里。必填状态由星号表达，无需重复写“可选”；留空后的回退、展示范围、稳定网址、隐私、无障碍和发布核对等有实际影响的信息必须保留。

写作编辑页的标签列表直接显示标签文字，无需打开编辑弹窗查看；空条目显示“未填写标签”。添加、编辑、排序和删除沿用原有控件。

项目、摄影和写作列表共用同一套排序规则：默认按添加顺序排列，最新添加在前；修改内容和调整展示位置不改变添加顺序。切换到“按展示顺序排列”后可拖动，松开后自动保存。展示顺序是从 1 开始的唯一位置，包含草稿；新增和导入内容追加到末尾，编辑页修改位置时插入到目标位置，其他内容自动顺移，删除后自动补齐编号。旧重复编号按原来的顺序整理，未编号文章按发布日期从新到旧初始化。构建会检查三类内容的编号连续且不重复。

项目首页与全部项目、摄影页使用展示顺序。写作页保留年份从新到旧的分组，组内按展示顺序排列；首页最近文章和 RSS 继续按发布日期排列。

项目编辑页的档案叠放图片列表直接显示小缩略图，已保存和刚上传的图片均可预览。每行标注当前层级：从上到下依次为“1 · 最上层”“2 · 中间层”“3 · 最底层”，越靠上越在前，第一张遮住其余图片；拖动后标注随当前位置实时更新。新增图片追加到列表末尾，放在已有图片下层。前台按从后到前的顺序绘制，遮挡、悬停和页面过渡均使用列表第一张作为最上层。用于「全部项目」列表的叠图，不足三张时缺少的位置用项目封面补齐。列表使用紧凑行高，空条目显示“未上传图片”；点击条目打开原上传编辑器，拖动排序和删除沿用原有控件。

项目编辑页不再手动填写发布和更新日期：首次保存时生成日期，原发布日期在后续保存中保留，更新日期随保存自动记录。日期用于内容记录与排序，不替代实际项目时间；文章仍可编辑发布日期。

项目只维护一个“项目状态”：进行中、已上线、实验、归档。精选卡片的状态文字和圆点颜色由此生成，不再填写“卡片状态”或“卡片色调”。旧数据优先保留原卡片显示的已知状态；没有卡片状态时保留原项目状态，导入旧文件沿用同一规则。

项目编辑页只维护必填的“项目时间”，支持年份或时间范围，如 `2026`、`2022-2025`；列表和详情显示同一时间。旧项目的年份已迁入项目时间，不再保存独立年份。导入旧文件时将 `year` 转为 `period`，已有 `period` 优先保留；缺少两者时沿用原导入规则暂用发布年份，并提示核对实际项目时间。

项目编辑页不再提供“我的职责”字段，职责说明按需写入项目正文。旧内容中的职责数据仍兼容，新增和导入项目不要求填写，也不生成“待补充”的职责占位。

照片、文章封面、项目封面和档案叠放图片保留原有文件选择与移除功能，并支持：

- 虚线区域位于照片标题和说明下方，宽屏、窄屏均使用相同顺序。
- 将一张图片拖入该区域（包括按钮、说明文字和空白处），或点击框内的“选择文件”按钮打开文件选择器。拖放先接收操作，再通过文件 MIME 类型、文件名和解码校验；不支持的格式也会显示失败原因。
- 点击区域空白处或用键盘聚焦该区域后，按 `Command+V` 或 `Ctrl+V` 粘贴复制的图片；焦点在“选择文件”按钮上时同样可粘贴。兼容粘贴事件落到页面主体，以及拖放仅提供文件列表的浏览器；只向当前聚焦的空上传区添加图片，其他文本字段保留原有粘贴行为。无需额外的粘贴按钮，也不通过点击读取剪贴板。
- 添加图片后隐藏选择区域，移除图片后重新显示。点击已添加的缩略图，或聚焦缩略图后按 Enter / 空格，可放大查看；点击预览卡片任意位置、关闭按钮或按 Esc 退出预览。
- 已添加图片时，图片下方先显示添加提示，再靠左显示“移除”按钮；沿用原有间距，按钮使用半透明红色背景和红色文字。

图片会先显示在当前表单中，点击“创建”或“保存”后才写入内容。移除照片时不立即显示必填错误，点击“创建”或“保存”时才校验。照片仍由原有流程自动压缩、更新尺寸并清理敏感元数据。拖放、选择文件和粘贴共用同一套校验；格式不支持、图片无法解码、空文件、超过 80 MB、一次添加多张、未读取到图片或文件读取失败时，上传区下方持续显示红色错误提示，说明原因和处理方式。有效图片添加成功后清除旧错误。

写作编辑侧栏在副标题下方提供可选的“文章封面”，复用同一上传组件。保存后封面存入 `public/media/articles/`，文章记录保存 `cover` 路径和 `coverAlt` 描述；详情页和分享预览使用该文章自己的封面。移除封面并保存后，详情页不显示封面，分享预览回退为全站默认图；旧文章没有封面字段时同样如此。为有信息意义的封面填写准确的“封面描述”，纯装饰封面可留空，留空时不会提供图片放大入口。文章封面不参与摄影集合的顺序、尺寸或拍摄参数自动预填。

摄影添加和编辑表单依次显示：照片、卡片比例与照片方向、画面描述与稳定短名、展示顺序、草稿、可公开的拍摄信息。卡片比例与照片方向在宽屏并排，窄屏按顺序排列。稳定短名旁的“根据描述生成”按钮会根据画面描述覆盖当前短名；首次发布后应保持短名不变。

添加照片后，“画面描述”默认填入原文件名，去掉最后的扩展名，保留中文、空格和文件名中的其他句点。手动填写的非空描述会保留；移除图片只清除自动填入的描述，再次选图时使用新文件名。自动预填不更改稳定短名，编辑已有照片时也不覆盖已保存的描述。文件选择、拖放和粘贴共用该默认值逻辑。

照片宽度和高度由处理后的发布资产自动读取，不在 CMS 表单中提供手动输入。内容记录仍保存这些数值，供图片比例计算和构建校验使用。卡片比例用于摄影页缩略图高度与分栏，照片方向用于横竖样式和首页竖图筛选；添加图片后两者立即根据解码后的实际宽高更新，文件选择、拖放和粘贴共用这一逻辑；保存时处理流程再次核对。宽高相等时按横图处理，与发布资产流程保持一致。

项目和文章的正文编辑器支持将图片拖入正文，或在正文中用相同快捷键粘贴；入口旁显示操作提示。文字粘贴保持编辑器原有行为。保存前为有信息意义的正文图片填写准确的替代文本。

CMS 顶部操作区按实际可用空间显示按钮，空间不足时由原生组件收进“更多”，不再因低于桌面断点而固定折叠。

CMS 的文本、短名、数字、日期和关系字段在点击“创建”或“保存”后显示填写错误；切换焦点不会提前触发。提交后仍保留原有校验，修改正确值后错误会更新。上传损坏文件、格式不符或一次多张的提示仍在添加时显示。

摄影上传后立即读取原图中的拍摄日期、相机、镜头、焦距、光圈、快门和感光度，并预填到实际表单值，无需先创建或保存。文件选择、拖放和粘贴共用这一流程；手动填写的非空值保留。移除或替换图片会清除上一次自动预填的值并取消旧请求，避免旧参数或迟到的结果混入另一张照片。没有可读取参数时显示普通说明，可继续手动填写。

参数读取仅使用本机开发接口，原图临时文件在读取后删除；接口只返回允许公开的字段，不自动填入地点、不返回 GPS、序列号或其他敏感信息。地点由用户手动填写可公开的范围。截图、剪贴板图片和已清理 EXIF 的发布资产可能不带拍摄参数；无法从画面推断出真实参数。保存时继续沿用发布资产压缩与敏感元数据清理流程。
