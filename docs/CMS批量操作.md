# CMS 批量操作

本机运行开发服务后，可在 `/keystatic` 的摄影、项目和写作列表使用多选。

三个列表默认按上传顺序倒序排列，最新上传的在最上面，最早上传的在最下面，新内容显示在顶部。点击表头可临时更改排序，刷新页面后恢复最新上传在前的默认顺序。摄影和项目点击“按展示顺序排列”后可拖动调整网站展示顺序，松开后仍自动保存；刷新只恢复 CMS 的浏览顺序。

添加摄影和项目时，“展示顺序”自动使用当前栏目已保存内容的最大序号加 1，包含草稿，默认排在网站展示的末尾；空栏目从 1 开始。编辑已有内容保留原序号，仍可手动调整。CMS 列表的上传顺序与网站展示序号独立，因此最新上传的内容在 CMS 顶部，但默认展示序号最大。

上传顺序保存在本机 `private/cms/upload-order-<栏目>.json`，被 Git 忽略，不进入公开内容或构建。旧内容没有独立上传时间时，首次读取按本机文件创建记录初始化（摄影优先使用发布资产的创建记录），随后固定保存；无法精确还原缺失的历史上传时间。文件创建时间相同时以稳定短名排序。新记录首次被列表发现时按创建顺序追加；编辑、发布状态修改和拖动排序不会改变其上传序号。删除记录后移除对应序号，同名重新上传会获得新序号。

列表上方、操作说明左侧显示“共 X 项”，统计当前列表中的全部条目（包括未滚动到的条目）。搜索时显示匹配结果数量，无匹配时显示“共 0 项”；删除后数量随当前列表更新。进入多选后仍保留列表数量，旁边另显示已选数量。窄屏时说明和操作按原有规则换行。

1. 点击“多选”，勾选条目；表头复选框全选当前列表。搜索后，全选仅包含搜索结果。更换搜索结果会清空选择。
2. 点击“设为已发布”或“设为草稿”，立即保存所选条目的发布状态。列表显示保存结果，刷新后状态仍保留。
3. 点击“删除所选”，确认条目名称和数量后，再点击“确认删除”。取消不会修改内容。
4. 点击“退出多选”恢复普通浏览和拖动排序。多选时点击行只切换选择，不打开编辑页。

保存期间暂时禁用选择与操作。若内容已在其他页面修改，操作会被拒绝，需刷新列表后重新选择。

删除关联项目或文章前，需先解除其他内容中的对应引用。删除照片会同时移走仅由所选照片使用的发布资产；共享资产保留。删除不重新编号其余条目，下次拖动排序时会统一更新展示顺序。

删除的内容和照片发布资产保存在本机 `private/content-trash/<批次标识>/`，保持原相对路径；该目录被 Git 忽略，不进入静态站点或公开仓库。需要手动恢复时，将对应文件放回原位置。项目和文章的媒体文件不随批量删除移除。

批量修改只作用于本地内容文件；公开网站仍需正常构建和部署才会更新。摄影全部改为草稿或删除后，公开摄影入口重定向至首页。

校验：`npm run test:batch` 覆盖状态持久化、正文格式保护、冲突拒绝、关联内容保护、照片资产处理及与拖动排序共享的保存锁；完整构建也会运行这些测试。
