# 摄影内容与上线指南

本指南对应当前摄影页：一页直接排列照片，点击打开灯箱，再次点击关闭。每张照片有独立地址。首版没有相册、摄影标签、筛选或加载批次。

## 内容和资产

- `src/content/photos/<短名>.json`：单张照片的公开记录；文件名决定 `/photos/<短名>/`。
- `public/media/photos/`：新照片经处理后的网页发布资产；内容记录使用 `/media/photos/<文件名>` 引用。
- `public/assets/figma-v03/photos/`：现有照片的公开资产，保留已有引用。
- `private/photos/`：可自行存放原件的本地目录，不进入版本控制，也不能在页面中引用。
- `src/lib/photos.ts`：按照 `order` 汇总照片，并只展示逐张核实的 `publicMetadata`。
- `src/components/photos/PhotosPage.astro`：摄影页与单张照片页共用的错落排布和灯箱视图。
- `src/scripts/photos-lightbox.ts`：打开、关闭、地址和焦点交互。
- `scripts/photos/audit.ts`：构建时检查尺寸、引用和敏感元数据。

照片记录示例：

```json
{
  "src": "/media/photos/lit-street.webp",
  "alt": "夜色中被暖光照亮的街巷建筑",
  "order": 1,
  "size": "tall",
  "orientation": "portrait",
  "width": 1200,
  "height": 1800,
  "publicMetadata": {
    "camera": "仅在核实后填写"
  }
}
```

`size` 控制当前排布中的视觉尺寸：竖图（`orientation: "portrait"`）使用 `tall`，横图（`orientation: "landscape"`）使用 `short`。`width`、`height` 必须与文件实际尺寸一致。`publicMetadata` 整体可省略；允许字段为 `capturedAt`、`place`、`camera`、`lens`、`focalLength`、`aperture`、`shutterSpeed`、`iso`。日期、地点与拍摄参数不能从别的照片复制过来充数，未知就留空。灯箱仅显示地点和已核实的相机、镜头、焦距、光圈、快门、ISO，不显示画面描述、拍摄日期和尺寸；画面描述保留为图片替代文本，日期和尺寸仍保存在内容记录中。

本机导入照片时，会先从原图提取拍摄日期、相机、镜头、焦距、光圈、快门和 ISO，预填到草稿的 `publicMetadata`，再清除公开图片中的 EXIF。直接在 Keystatic 中保存新照片草稿时，本地照片准备脚本也会在处理图片前预填这些字段。地点不会根据照片坐标自动填写；发布前仍需逐项核对。

## 组件照片管理

在 CMS 侧边栏「照片组件」中管理三组独立选图：

- **首页扇形照片**：亮色首页使用，最多 7 张，悬停文字使用照片的画面描述。
- **首页拖拽照片**：暗色首页使用，最多 6 张，支持横图与竖图。
- **文字悬停照片**：关于页「走走拍拍」与设计系统示例使用，选择 6 张；不足 6 张已发布照片时只显示文字。

摄影列表和照片组件列表最左侧显示正方形缩略图。点击「添加」从已有摄影记录中按画面描述搜索选择照片，拖动列表调整组件内的顺序，然后保存。组件配置保存在 `src/data/photo-components/`，引用照片的稳定短名，不复制图片与描述。摄影页的展示顺序独立维护。草稿、已删除的照片和重复选择不会在组件中重复或公开展示；清空列表隐藏对应组件。原有首页勾选照片已迁移到扇形配置，拖拽和文字悬停配置已预填原选图规则对应的照片。

## 新增或替换照片

1. 在自己的独立备份中保存原件。公开资产只使用已筛选、压缩并去除敏感 EXIF 的副本。
2. 从原件生成适合网页使用的副本，放在 `public/media/photos/`。最长边不超过 2400px、单张小于 2MB；实际导出尺寸和质量应按照片内容调整，尽量减少体积。清除敏感 EXIF/XMP，并检查可识别的第三方人物或私人信息。Astro 会原样复制 `public/` 中的文件，不会在构建时自动压缩。
3. 新增对应 JSON；确认 `alt` 准确、`order` 不重复、图片尺寸正确，必要时添加经过核实的公开参数。
4. 运行 `npm run photos:audit` 和 `npm run build`。审计会拒绝缺失或孤立的公开文件、错误尺寸、EXIF/XMP 和 GPS/序列号等敏感字段。
5. 在桌面和手机查看摄影页；打开不同照片，确认图片和详情一致，刷新单张地址后仍是同一张；检查关闭、`Esc` 和返回键后焦点与地址正确。

公开地址一旦使用，不要仅因照片标题或排布变化而更改短名。需要更换已经公开的短名时，为旧地址设置跳转。

当前 16 张照片是页面展示素材，摄影事实仍需作者逐张确认。项目早期的相册与标签方案保留在历史版本文档中，不属于当前开发依据。

目前网格和灯箱共用内容记录中的一份 `src` 资产，网格中的后续照片使用延迟加载。新增大量照片前，应为网格生成较小的预览图，并让灯箱按需加载较大的发布图；这需要同步扩展内容字段、组件和发布审计。
