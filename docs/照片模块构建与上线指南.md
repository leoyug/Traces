# 摄影内容与上线指南

本指南对应当前摄影页：一页直接排列照片，点击打开灯箱，再次点击关闭。每张照片有独立地址。首版没有相册、摄影标签、筛选或加载批次。

## 内容和资产

- `src/content/photos/<短名>.json`：单张照片的公开记录；文件名决定 `/photos/<短名>/`。
- `public/assets/figma-v03/photos/`：页面使用的公开图片。目录名称沿用现有资源路径，不代表必须从 Figma 获取照片。
- `private/photos/`：可自行存放原件的本地目录，不进入版本控制，也不能在页面中引用。
- `src/lib/gallery.ts`：按照 `order` 汇总照片，并只展示逐张核实的 `publicMetadata`。
- `src/components/photos/PhotoGallery.astro`：当前错落排布和灯箱结构。
- `src/scripts/gallery-lightbox.ts`：打开、关闭、地址和焦点交互。
- `scripts/photos/audit.ts`：构建时检查尺寸、引用和敏感元数据。

照片记录示例：

```json
{
  "src": "/assets/figma-v03/photos/photo-01.jpg",
  "alt": "夜色中被暖光照亮的街巷建筑",
  "order": 1,
  "size": "tall",
  "orientation": "portrait",
  "width": 1200,
  "height": 1800,
  "publicMetadata": {
    "camera": "仅在核实后填写"
  }
}
```

`size` 控制当前排布中的视觉尺寸（`tall` 或 `short`），`orientation` 表示图片横竖方向。`width`、`height` 必须与文件实际尺寸一致。`publicMetadata` 整体可省略；允许字段为 `capturedAt`、`place`、`camera`、`lens`、`focalLength`、`aperture`、`shutterSpeed`、`iso`。日期、地点与拍摄参数不能从别的照片复制过来充数，未知就留空。灯箱始终显示准确画面描述和实际尺寸。

## 新增或替换照片

1. 在自己的独立备份中保存原件。公开资产只使用已筛选、压缩并去除敏感 EXIF 的副本。
2. 将公开图片放在 `public/assets/figma-v03/photos/`，最长边不超过 2400px，文件不超过 2MB。检查图片中是否有可识别的第三方人物或私人信息。
3. 新增对应 JSON；确认 `alt` 准确、`order` 不重复、图片尺寸正确，必要时添加经过核实的公开参数。
4. 运行 `npm run photos:audit` 和 `npm run build`。审计会拒绝缺失或孤立的公开文件、错误尺寸、EXIF/XMP 和 GPS/序列号等敏感字段。
5. 在桌面和手机查看摄影页；打开不同照片，确认图片和详情一致，刷新单张地址后仍是同一张；检查关闭、`Esc` 和返回键后焦点与地址正确。

公开地址一旦使用，不要仅因照片标题或排布变化而更改短名。需要更换已经公开的短名时，为旧地址设置跳转。

当前 16 张照片是页面展示素材，摄影事实仍需作者逐张确认。项目早期的相册与标签方案保留在历史版本文档中，不属于当前开发依据。
